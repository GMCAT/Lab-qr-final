3. ปัญหาและสาเหตุหลัก / Root cause

Blocking error 1:
- อาการ: frontend/index1.html มี Unexpected end of input
- สาเหตุ: ไฟล์ปะปนข้อความสนทนา โค้ดซ้ำ และ JavaScript ที่ปิด block ไม่ครบ
- แก้: archive snapshot เดิมและแทน index1.html ด้วย compatibility redirect

Blocking error 2:
- อาการ: backend อาจแจ้งไม่พบ JWT_SECRET แม้สร้าง .env ตาม README แล้ว
- สาเหตุ: npm scripts เรียก node โดยไม่ได้โหลด .env
- แก้: ใช้ node --env-file=.env และกำหนด Node ขั้นต่ำ 20.6

Routing regression:
- อาการ: เปิดหน้า main โดยไม่มี hash ขณะยังไม่ login อาจเก็บ #/admin เป็น redirect แล้ว user ถูกส่งไปหน้าที่ไม่มีสิทธิ์หลัง login
- สาเหตุ: router ใช้ #/admin เป็น default ก่อนตรวจ authentication
- แก้: default เป็น #/login สำหรับผู้ไม่มี token และ #/admin สำหรับผู้มี token

Configuration mismatch:
- อาการ: UPLOAD_DIR มีใน .env.example แต่ backend ไม่เคยใช้
- สาเหตุ: path uploads ถูก hardcode หลายจุด
- แก้: resolve UPLOAD_DIR ครั้งเดียวและใช้กับ static serving, directory creation และ Multer
